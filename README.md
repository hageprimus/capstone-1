# Transaction Ledger Application

This application accepts transaction data in the form of a .CSV or .JSON file 
and allows the user to view and manipulate the data within in various forms.

## Features
* Import and export transaction data (.CSV or .JSON)
* View reports based on the data, such as filtering by date or vendor
* Generate custom reports based on user-defined parameters

## How To Use
* Clone the project and run LedgerApp with a compatible Java runtime. 
* Follow the console instructions in order to interface with the given transaction data.
* The project was built under the Amazon Coretto 17.0.21 JDK.
